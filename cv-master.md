# CV 마스터 파일

마지막 업데이트: 2026-11-05

CV와 LinkedIn 작업의 기준 문서. 대화가 길어지거나 새 대화를 시작해도 이 파일을 먼저 읽고 이어서 작업한다.

- `3. CV 본문`이 현재 확정본이다. 수정 사항은 여기에 반영한다.
- `[ ]`는 채울 부분, `(확인)`은 사실 확인이 필요한 부분이다.
- 새 대화에서는 "cv-master.md를 읽고 이어서 작업해 줘"라고 시작한다.

## 1. 작성 규칙

| 항목 | 규칙 |
|---|---|
| 철자 | 영국식: programme, organisation, organised, recognised, -ise |
| 대시 | em dash(—) 쓰지 않음(AI 문체 신호). en dash(–)는 기간과 'ASEAN–Korea' 같은 관계 표현에만 |
| 고유명사 | 공식 표기 그대로(하이픈): ASEAN-Korea Cooperation Fund, Korea-Indonesia Connection, CAMPUS Asia-AIMS, 2026 ASEAN-Korea Academic Conference |
| 숫자 | 한눈에 보이도록 아라비아 숫자(4, 50+, 100+) |
| 인용 | 작은따옴표 'My ASEAN Friends', 쉼표는 따옴표 밖 |
| 쉼표 | 마지막 and 앞 쉼표 없음(Korean, English, Indonesian and Malay) |
| 시제 | 현재 업무는 현재형, 끝난 업무는 과거형 |
| 동사 | 불릿은 동사로 시작. 피할 표현: aspiring, assisting with, participated in, growing expertise, real field experience, Successfully, comprehensive, fostering |
| 숫자의 주인 | 사업 전체 수치는 '사업 규모'로만 쓰고 본인 성과처럼 쓰지 않음 |
| 사실 확인 | 확인되지 않은 숫자·직함·명칭은 쓰지 않음(평판 조회 대비). 대외비 수치는 쓰지 않음 |
| 서식 | 첫 줄 기관(굵게) + 기간(굵게, 오른쪽) / 둘째 줄 직함(굵게) / 설명 줄(기울임, 필요할 때만) / 불릿. 왼쪽 정렬. 항목이 페이지에서 갈라지지 않게 'Keep with next' |
| 섹션 순서 | Profile → Education → Experience → International Programmes → Community Engagement → Awards and Scholarships → Skills and Interests |
| 섹션 구성 원칙 | Experience = 요약문의 'organiser' 세 기관, International Programmes = 요약문의 'participant' 두 프로그램 |
